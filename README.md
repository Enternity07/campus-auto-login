# 校园网开机自动登录

适用于 Windows 10/11 的 Dr.COM 校园网认证脚本。设置一次后，每次登录 Windows 会在后台运行，检测到校园网未认证时使用本人账号自动登录；运行期间每 30 秒检查一次。

当前版本针对认证服务器 `172.30.255.42`、接入控制器 `172.30.255.41` 的实际页面适配。其他学校或不同认证页面需要修改适配逻辑。

## 一次设置，以后开机自动联网

1. 在 GitHub 点击 **Code → Download ZIP**，将压缩包完整解压到固定位置。
2. 打开里面的 **校园网自动重连** 文件夹，双击 **启动校园网助手.cmd**。
3. 输入 **2**，填写和网页相同的本人校园网账号、密码。输入密码时屏幕不显示字符。
4. 输入 **5**，启用登录 Windows 后自动运行。
5. 如果现在就要开始检测，输入 **1**。之后可关闭菜单窗口。

以后开机进入 Windows，无需手动打开程序。电脑需要先连上校园 Wi-Fi 或网线；使用 Wi-Fi 时，在 Windows 中为该网络启用“自动连接”。

无需安装 Python、浏览器插件或其他依赖，也无需管理员权限。程序使用 Windows 自带的 PowerShell 5.1。

## 常用菜单

| 选项 | 操作 |
| --- | --- |
| 1 | 启动后台自动重连 |
| 2 | 设置或修改账号密码，解除失败暂停 |
| 3 | 停止后台检测 |
| 4 | 查看最近日志 |
| 5 | 启用登录 Windows 后自动运行 |
| 6 | 取消自动运行 |
| 7 | 只读检测当前认证状态 |
| 8 | 打开认证网页 |

详细说明见 [使用说明](校园网自动重连/使用说明.md)。

## 凭据和运行限制

- 账号密码由使用者在本机输入。密码通过 Windows DPAPI 加密，绑定当前电脑和 Windows 用户，保存在程序目录的 `.data/credential.xml`。凭据和运行日志已加入 `.gitignore`，不要手动上传或分享 `.data`。
- 只向指定校园认证服务器提交登录。当前学校接口使用 HTTP，传输加密能力与原网页登录方式相同。
- 程序使用有效账号重新认证；需要验证码或短信时暂停并提示人工处理。
- 认证失败会延迟重试，连续被拒绝最多尝试 3 次；识别到密码、验证码、欠费等提示时立即暂停。
- “开机自动运行”指当前用户登录 Windows 后启动。电脑关机、睡眠或休眠时不能执行登录，恢复运行后继续检测。
- 修改账号后重新选择菜单 1。移动文件夹前先选择菜单 6，移动后再选择菜单 5。卸载时先选择菜单 6 和菜单 3，再删除文件夹。

## 文件和验证

- `校园网自动重连/CampusAutoLogin.ps1`：状态检测、认证、加密凭据及自启动管理。
- `校园网自动重连/启动校园网助手.cmd`：双击运行的菜单入口。
- `校园网自动重连/tests/Test-CampusAutoLogin.ps1`：26 项验证，包括在线时不提交凭据、掉线重登确认、重试暂停、JSONP 解析、密码特殊字符及 DPAPI 加密。

在仓库根目录运行测试：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\校园网自动重连\tests\Test-CampusAutoLogin.ps1"
```

测试使用模拟凭据与接口，不提交实际校园网登录。
