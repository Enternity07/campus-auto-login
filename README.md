# 深圳大学校园网开机自动登录

面向**深圳大学宿舍区及公共 / 教学区**的 Windows 10/11 校园网助手，分别适配 Dr.COM / ePortal 与深澜 SRun。设置一次后，每次登录 Windows 会在后台运行，检测到校园网未认证时使用本人账号自动登录；运行期间每 30 秒检查一次。

## 深圳大学适用范围

| 网络区域 | 认证入口 | 本项目支持情况 |
| --- | --- | --- |
| 学生宿舍区，使用本文所列 ePortal 页面 | `http://172.30.255.42/a79.htm`，接口端口 `801` | 已适配账号密码认证、开机启动和掉线重连 |
| 公共 / 教学办公区、图书馆等使用学校统一上网入口的区域 | `https://net.szu.edu.cn/` | 已实现 SRun IPv4 账号密码认证，完成真实页面只读核对与协议测试；实际账号登录需使用者验证 |

宿舍区当前适配认证服务器 `172.30.255.42` 和接入控制器 `172.30.255.41`。公共区入口由[深圳大学信息中心](https://www1.szu.edu.cn/nc/view.asp?id=639)及[图书馆无线网络说明](https://www.lib.szu.edu.cn/space-and-facilities/wlan)确认。两个脚本都会读取当前 IP，请以电脑实际弹出的认证页面选择版本。

## 一次设置，以后开机自动联网

1. 在 GitHub 点击 **Code → Download ZIP**，将压缩包完整解压到固定位置。
2. 打开里面的 **校园网自动重连** 文件夹，按上表双击公共区或宿舍区启动文件。
3. 输入 **2**，填写和对应区域认证网页相同的本人账号、密码。输入密码时屏幕不显示字符。
4. 输入 **5**，启用登录 Windows 后自动运行。
5. 如果现在就要开始检测，输入 **1**。之后可关闭菜单窗口。

以后开机进入 Windows，无需手动打开程序。电脑需要先接入对应的学校网络；使用 Wi-Fi 时，在 Windows 中为实际使用的网络启用“自动连接”。

无需安装 Python、浏览器插件或其他依赖，也无需管理员权限。程序使用 Windows 自带的 PowerShell 5.1。

## 常用菜单

| 选项 | 操作 |
| --- | --- |
| 1 | 启动后台自动重连 |
| 2 | 设置或修改账号密码，解除失败暂停 |
| 3 | 停止后台检测 |
| 4 | 查看最近日志 |
| 5 | 启用登录 Windows 后自动运行 |
| 6 | 取消自动运行 |
| 7 | 只读检测当前认证状态 |
| 8 | 打开认证网页 |

原有的“启动校园网助手.cmd”仍为宿舍区入口。公共区脚本及其依赖需保留在同一目录。

## 凭据和运行限制

- 账号密码由使用者在本机输入。密码通过 Windows DPAPI 加密，绑定当前电脑和 Windows 用户，保存在程序目录的 `.data/credential.xml`。凭据和运行日志已加入 `.gitignore`，不要手动上传或分享 `.data`。
- 宿舍区只向指定的 ePortal 服务器提交登录；该接口使用 HTTP。公共区只使用 `https://net.szu.edu.cn:443`，保留证书校验且认证请求不跟随跳转。
- 程序使用有效账号重新认证；需要验证码或短信时暂停并提示人工处理。
- 认证失败会延迟重试，连续被拒绝最多尝试 3 次；识别到密码、验证码、欠费等提示时立即暂停。
- “开机自动运行”指当前用户登录 Windows 后启动。电脑关机、睡眠或休眠时不能执行登录，恢复运行后继续检测。
- 修改账号后重新选择菜单 1。移动文件夹前先选择菜单 6，移动后再选择菜单 5。卸载时先选择菜单 6 和菜单 3，再删除文件夹。

## 文件和验证

- `校园网自动重连/CampusAutoLogin.ps1`：状态检测、认证、加密凭据及自启动管理。
- `校园网自动重连/SzuPublicAutoLogin.ps1`：公共区 SRun 认证、验证码检查与 HTTPS 请求。
- `校园网自动重连/SrunCodec.cs`：公共区 bx1 编码、HMAC-MD5 和 SHA1 校验。
- `校园网自动重连/启动深大公共区助手.cmd`：公共区版菜单入口。
- `校园网自动重连/启动深大校园网助手.cmd`：深圳大学宿舍区版的菜单入口。
- `校园网自动重连/启动校园网助手.cmd`：原有菜单入口。
- `校园网自动重连/tests/`：宿舍区回归测试、公共区流程测试，以及学校前端编码函数生成的模拟凭据测试向量。

在仓库根目录运行测试：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\校园网自动重连\tests\Test-CampusAutoLogin.ps1"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\校园网自动重连\tests\Test-SzuPublicAutoLogin.ps1"
```

测试使用模拟凭据与接口，不提交实际校园网登录。
