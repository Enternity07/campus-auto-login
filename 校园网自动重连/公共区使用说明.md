# 深圳大学公共 / 教学区自动登录

公共区上网认证入口：**[https://net.szu.edu.cn/](https://net.szu.edu.cn/)**。

深圳大学信息中心的[脚本认证指南](https://www1.szu.edu.cn/nc/view.asp?id=639)提供的完整页面为 `https://net.szu.edu.cn/srun_portal_pc?ac_id=1&theme=proyx`。图书馆的[无线网络服务说明](https://www.lib.szu.edu.cn/space-and-facilities/wlan)也将 `SZU_WLAN` 的网页认证入口列为 `https://net.szu.edu.cn/`。

本脚本面向使用此入口的公共、教学办公和图书馆网络，使用深澜 SRun 的 IPv4 账号密码认证。程序会从学校页面读取当前 IP 和接入控制器，在登录前获取新 challenge，再生成 HMAC-MD5、bx1 加密信息和 SHA1 校验值。账号密码通过学校的 HTTPS 入口提交。

## 首次设置

1. 在 GitHub 点击 **Code → Download ZIP**，完整解压到固定目录。请保留同目录的 `CampusAutoLogin.ps1` 和 `SrunCodec.cs`，不要只复制一个脚本。
2. 先连接学校公共区网络，例如实际覆盖区域的 **SZU_WLAN**；无线网络可勾选 Windows 的“自动连接”。
3. 双击 **启动深大公共区助手.cmd**。
4. 输入 **2**，保存与 `net.szu.edu.cn` 页面登录成功时相同的本人上网账号、密码。不要根据旧教程猜测密码长度或默认密码。
5. 输入 **5**，启用当前用户登录 Windows 后自动运行。
6. 输入 **1**，立即开始后台检测。看到已启动后即可关闭菜单窗口。

之后每次进入 Windows 自动检测；公共区认证掉线时重新登录。菜单 **3** 停止后台程序，**4** 查看日志，**6** 取消开机自动运行，**7** 只读检查接口与认证页面，**8** 打开认证网页。

## 凭据、区域与验证

- 公共区配置保存在 `.data/public/credential.xml`，密码使用 Windows DPAPI 加密。它与宿舍区配置分开，公共区脚本不会读取宿舍区密码。
- 两个版本的后台进程、自启动项和日志分别管理。按当前需要使用对应区域的启动文件；更换常用区域时，可先在旧版本选择菜单 6 和 3，再设置新版本。
- 仅向 `https://net.szu.edu.cn:443` 发送公共区请求，保留 Windows 证书校验。登录接口不自动跟随跳转；只有读取页面时允许同域 HTTPS 跳转。
- 登录前检查学校的验证码要求。出现验证码、账号锁定或强制改密时暂停，需打开网页登录处理；连续认证被拒绝最多尝试 3 次。
- 当前实现 IPv4 账号密码认证；短信、动态口令、第三方单点登录或学校后续更换的协议需要另行适配。
- 电脑睡眠、休眠、关机时无法执行。该脚本在用户进入 Windows 后启动，不处理 Windows 登录前的联网。
- 已使用学校实际页面和状态接口进行只读核对，编码测试向量来自学校前端的纯编码函数；**未使用真实公共区账号提交登录**。首次使用请通过菜单 4 查看是否确认恢复在线。

## 命令行

```powershell
# 只读检测，不加载校园网账号密码
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\SzuPublicAutoLogin.ps1 -Action Diagnose

# 设置过公共区账号后，进行一次检测，掉线时尝试认证
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\SzuPublicAutoLogin.ps1 -Action Once
```
