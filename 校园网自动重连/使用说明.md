# 校园网自动重连

适用于本次提供的 Dr.COM 认证服务器 `172.30.255.42`，Windows 10/11 自带 PowerShell 即可运行，无需安装 Python、浏览器插件或管理员权限。

## 开始使用

1. 将整个「校园网自动重连」文件夹保存在一个固定位置。
2. 双击 **启动校园网助手.cmd**，输入 **2**，设置账号密码。
3. 输入与认证网页相同的本人校园网账号、密码。输入密码时屏幕不会显示字符，这是正常现象。
4. 输入 **5**，启用当前 Windows 用户登录后自动运行。此操作只需设置一次，以后开机进入 Windows 就会自动检测并认证校园网。
5. 如果现在就要开始检测，输入 **1**。看到已启动后台检测后，可以关闭菜单窗口。

电脑需要先连接校园 Wi-Fi 或网线；使用 Wi-Fi 时，在 Windows 中为校园网络勾选“自动连接”。

程序每 30 秒检查一次校园网认证状态。服务器确认掉线后，程序使用保存的账号密码重新登录，并再次查询状态确认结果。它会重新读取当前电脑 IP，不沿用原链接中的旧 IP。

## 常用操作

| 需要做什么 | 菜单选项 |
| --- | --- |
| 启动后台重连 | 1 |
| 修改账号密码或解除失败暂停 | 2，保存后再选 1 |
| 停止后台运行 | 3 |
| 查看是否恢复登录、失败原因 | 4 |
| 登录 Windows 后自动运行 | 5 |
| 取消自动运行 | 6 |
| 只检查，不提交账号密码 | 7 |
| 打开认证网页 | 8 |

重复启动不会创建多个检测进程。停止后，当前正在进行的网络请求可能需要几秒钟才能结束。修改账号时会停止旧进程，保存后请重新启动。

## 账号和运行限制

- 这是使用本人账号自动重新认证的工具，需要有效账号和密码。它不提供免账号上网，也不会绕过验证码、短信验证或学校的停网限制。
- 密码通过 Windows DPAPI 加密，保存在同目录 `.data/credential.xml`，绑定本机当前 Windows 用户。换电脑或换 Windows 用户后需要重新设置。不要分享 `.data` 文件夹。
- 日志位于 `.data/reconnect.log`，不记录账号、密码或登录请求 URL。
- 学校当前提供的认证接口使用 HTTP，登录时与原网页一样不具备 HTTPS 的传输加密。程序只向指定认证服务器发送凭据，并禁止跟随接口重定向。
- 程序在认证正常时只查询状态；认证不在线才提交登录。校园网服务器无法访问时会延迟重试；认证被明确拒绝最多尝试 3 次，间隔 2 分钟、4 分钟。识别到密码、验证码、欠费等提示时会立即暂停。
- 如果页面启用验证码、短信或改变认证方式，程序会暂停并提示手动处理。处理后通过菜单 2 重新保存账号，再选 1。
- **电脑睡眠、休眠、关机时程序不能运行**。唤醒并恢复校园网连接后，后台程序会继续检查。此工具不会阻止电脑休眠。
- 「认证正常」表示学校认证服务器报告账号在线，不保证学校外网出口、DNS 或所有网站都可用。
- 取消自动运行并停止后台程序后，可直接删除整个文件夹卸载。移动文件夹前请先取消自动运行，移动后重新开启。

## 命令行（可选）

```powershell
# 只读检测，不提交账号密码
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\CampusAutoLogin.ps1 -Action Diagnose

# 手动进行一次检查，需要已设置账号，掉线时会尝试登录
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\CampusAutoLogin.ps1 -Action Once

# 前台运行检测循环（Ctrl+C 停止）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\CampusAutoLogin.ps1 -Action Worker
```

此程序根据实际登录页、前端脚本及只读状态接口适配。账号密码由使用者在本机输入，登录 Windows 后自动运行由菜单 5 启用。
